Scraping de leads

Scraping manual (CLI)

Sem --sourceId = todas as fontes ativas.

npm run scrape:manual
npm run scrape:manual -- --sourceId=260

Scraping pelo painel

Scraping → fonte → Executar Agora. Equivalente ao curl abaixo.

curl -X POST -H "x-panel-token: $PANEL_RUN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sourceId":260}' \
  http://localhost:3000/api/scrape/run

Listar fontes (IDs)

curl -s http://localhost:3000/api/sources | jq '.data[] | {id,name,is_active}'

Fontes CNPJ (SP + OpenCNPJ/CNPJA)

13 fontes cnpj-* com uf=SP.

curl -s http://localhost:3000/api/sources | jq '.data[] | select(.name|startswith("cnpj")) | {id,name}'
npm run scrape:manual -- --sourceId=260
CNPJ_DEFAULT_UF=SP

Campanhas de e-mail

Disparo pelo painel

Email → campanha → Disparar / Dry Run / Teste.

Status e cotas (API)

curl -s http://localhost:3000/api/email/status | jq

Enviar e-mail de teste

curl -X POST -H "x-panel-token: $PANEL_RUN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"toEmail":"voce@gmail.com","subject":"Teste","template":"Olá {{nome}}"}' \
  http://localhost:3000/api/email/test

Campanha dry-run (simula sem enviar)

curl -X POST -H "x-panel-token: $PANEL_RUN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"subject":"Oi","template":"Olá {{nome}}","dryRun":true}' \
  http://localhost:3000/api/email/run

Histórico e analytics

curl -s "http://localhost:3000/api/email/history?limit=20" | jq
curl -s "http://localhost:3000/api/email/analytics?days=7" | jq

Diagnóstico & troubleshooting

Snapshot operacional (API agregada)

Leads, e-mail, scraping e config em um JSON — substitui vários curls.

curl -s http://localhost:3000/api/ops/snapshot | jq

401 Unauthorized nos endpoints sensíveis

Endpoints de scrape/e-mail exigem x-panel-token quando PANEL_RUN_TOKEN está no .env.

curl -H "x-panel-token: $PANEL_RUN_TOKEN" ...
reinicie o servidor após mudar .env

E-mail não envia — checklist

1) Cotas → 2) Teste isolado → 3) Dry-run da campanha.

curl -s http://localhost:3000/api/email/status | jq '.remaining'
curl -X POST -H "x-panel-token: $PANEL_RUN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"toEmail":"voce@gmail.com","subject":"Teste","template":"Olá {{nome}}"}' \
  http://localhost:3000/api/email/test

Tracking desabilitado (pixel/cliques)

Sem APP_BASE_URL público no .env, links de tracking não são injetados.

APP_BASE_URL=https://seu-dominio.com

Card “E-mail contatável” zerado

Servidor com código antigo em memória — reinicie npm run dev.

curl -s http://localhost:3000/api/dashboard/summary | jq '.data.emailBreakdown'

Descobrir IP público (autorizar serviços)

curl -s https://api.ipify.org
